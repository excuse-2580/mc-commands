# 我的世界指令大全

收录 **77 条指令、217 个可点击复制的示例**，覆盖 Java 版与基岩版。

## 在线使用

https://excuse-2580.github.io/mc-commands/

## 功能

- **搜索**：支持指令名、中文说明、示例内容、备注全文匹配，输入「传送」也能找到 /tp
- **版本切换**：全部 / Java 版 / 基岩版，基岩独有指令（如 /tickingarea、/camerashake、/ability）单独标注
- **分类筛选**：速查 / 基础 / 世界 / 物品 / 实体 / 方块 / 红石 / 显示 / 管理
- **点击即复制**：语法模板和每条示例都能一键复制，直接粘进游戏聊天栏

## 收录范围

速查（目标选择器 @p @a @e @s、相对坐标 ~ ^）、基础（gamemode / give / tp / gamerule / effect / enchant）、
世界（time / weather / locate / worldborder）、物品（item / loot / recipe）、
实体（summon / execute / data）、方块（setblock / fill / clone）、
红石（scoreboard / function / datapack / team / bossbar / tick）、
显示（tellraw / title / particle / playsound）、管理（op / ban / whitelist / reload）。

## 技术

纯前端单文件，原生 HTML + CSS + JavaScript，无框架、无外部依赖、无网络请求。

## 说明

语法以 **Java 版 1.20–1.21** 与基岩版常见写法为准，不同版本细节可能有差异，以你实际游戏为准。
涉及 NBT 与组件（1.20.5+）的部分已在备注中标注版本差异。
